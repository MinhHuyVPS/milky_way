# Shared Knowledge

This directory stores reusable project knowledge shared by developers.

## Research

Save investigation results, findings, relevant source files, and evidence.

Suggested filename: `YYYY-MM-DD-topic.md`

## Decisions

Save agreed technical decisions, alternatives considered, and reasons.

## Guidelines

- Record useful findings, not every AI conversation.
- Include references to relevant files and tests.
- Do not store credentials, access tokens, secrets, or sensitive personal data.
- Review findings before committing them.
- Share knowledge through Git commits and pull requests.
