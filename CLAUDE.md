# Project Development Instructions

## Shared Knowledge

Before investigating a task, check relevant files under `shared-knowledge/`.

When an investigation produces reusable findings, propose a Markdown document under `shared-knowledge/research/`.

Record important agreed technical decisions under `shared-knowledge/decisions/`.

Do not assume an investigation is shared with other developers until its result has been committed and pushed to the shared Git repository.

Never save credentials, access tokens, or other secrets in shared knowledge.
